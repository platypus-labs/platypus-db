SQL editor

Write it once, run it anywhere.

An editor that knows your schema and remembers what you ran.

  • Completion from the schema

    Tables, columns and aliases in scope, and whole JOINs completed from the foreign keys with the alias and the ON condition.

    SELECT o.id, c.name FROM orders o
JOIN customers c ON c.id = o.customer_id  # completed

  • Statement or script

    Ctrl+Enter runs the statement under the cursor, Alt+X the whole script.

    2keys

  • Parameters

    :name and ? placeholders, asked in a dialog before running.

    :city:from?

  • History

    The queries you ran, saved scripts and .sql files, with a query manager that shows the time of every statement.

  • Notebooks

    SQL and Markdown cells in one tab; save it as a .pnb file or export it to HTML.

Data

See and change rows without writing SQL.

  • A million rows, no wait

    A canvas grid that reads a page at a time.

    178fps

  • Edit, then save all or nothing

    Changes are collected in the grid, the SQL is previewed, and the save is all or nothing. Every save leaves an undo script.

    - status = 'pending'+ status = 'shipped'+ INSERT 1 row

  • The value, in full

    Long text, JSON, XML, hex and images in a value panel (F7); geometries on a map panel.

    JSONXMLImageMap

  • Charts and pivots

    A result switches between the grid and a chart from the status bar, and Pivot builds a pivot table from it.

    BarLineScatterPiePivot

Schema

Know the schema, change it safely.

  • A table editor that shows its SQL

    Add and change columns, indexes and keys; the ALTER TABLE is shown before it runs.

    + ADD COLUMN coupon_code varchar(32)- DROP COLUMN shipped_at

  • Notes and tags

    The database's own comments, your notes and tags on every table and column.

    #pii#coreMarkdown

  • ER diagram

    Drawn from the foreign keys and laid out for you; export it to PNG or SVG.

  • Docs in one file

    A schema as a Markdown file or a single HTML file that works offline, with an ER diagram.

  • Compare and migrate

    Compare a schema with another one; the script that makes it like this one opens in the SQL editor, also as a Flyway or Liquibase migration.

Performance

See why a query is slow.

  • Explain analyze, rolled back

    Runs the statement for real times, rolls back what it changed, tints each step by its share of the time and suggests an index.

    Seq Scan on orders412 ms
    Hash Join96 ms
    Index Scan customers21 ms

  • Server activity

    Sessions, locks and who blocks whom on PostgreSQL, MySQL, MariaDB and SQL Server; cancel a statement or end a session after a confirmation.

Safety

Production stays production.

  • Colors you can't miss

    The window frame takes the connection's color.

    developmenttestproduction

  • Manual commit on production

    Production opens in manual commit; every change is listed and confirmed before it runs.

  • Read only when you say so

    A connection can be read only, and the lock button does the same for one editor tab. Passwords stay in the system keychain.

Import and export

Move data anywhere.

  • Files in and out

    CSV, JSON, Parquet, Excel and more, streamed to disk or to S3.

    CSVJSONParquetExcelSQLS3

  • Between databases

    Copy a table or a whole schema from any database to any other.

    PostgreSQL → MySQLSQL Server → SQLite

Agents and CLI

Ready for agents, read only by default.

  • An MCP server and a command line

    Every MCP client can use your saved connections. Each connection gives agents no access, read only (the default) or read and write.

    $ platypus-db --mcp
# or the CLI, one JSON document
$ platypus query "select 1"

  • You approve the changes

    A change an agent wants to run opens a dialog in the app first.
