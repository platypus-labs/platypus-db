How they connect

What each one needs.

Every database gets the editor, the grid and the navigator. The notes say what differs; the oldest server versions are in FEATURES.md.

DatabaseConnects throughNotes
PostgreSQLnative protocolSeveral databases per connection, partitions, PostGIS, arrays and composite types
MySQL, MariaDBnative protocolEXPLAIN ANALYZE needs MySQL 8.0.18
SQL Server, Azure SQLTDSTOP (n), [names], several result sets
OracleOracle Instant Client, downloaded on first usePL/SQL blocks, real cancel, navigator, DDL

DuckDBembedded, Arrow resultsAlso opens CSV, JSON, Parquet and Excel files as databases
libSQL / TursoHrana over HTTPToken in the password or in authToken
MongoDBofficial drivermongosh syntax; no transactions or data editing
Redisredis crate (RESP3, rustls)Commands in the editor; key types as tables, edited in the grid; JSON with RedisJSON

Apache Cassandra, ScyllaDBscylla crate (rustls)CQL; keyspaces, tables, views, types and functions in the navigator; edited in the grid by primary key

Missing a database?

Any database with an ADBC driver works today, and on Windows any ODBC driver or DSN. Ask for a native driver on GitHub.
