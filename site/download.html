From source

Build it yourself.

Rust 1.99 or newer, Node.js 24 or newer and the Tauri prerequisites. The full guide is DEVELOPMENT.md.

$ git clone https://github.com/PaoloCisly/platypus-db
$ cd platypus-db/apps/desktop
$ npm install
$ npm run tauri build
