O que funciona onde

"Linhas" é a edição na grade. "Admin" são as abas do servidor de Atividade do servidor… (sessões, locks, painel, instruções mais custosas, tabelas e índices, parâmetros, usuários e papéis, manutenção). Um traço quer dizer "não disponível"; "não testado" quer dizer que o app não bloqueia, mas nada o executa.

"Admin" no CockroachDB e no YugabyteDB está desativado porque esses servidores não têm partes do que as abas chamam (o CockroachDB não tem pg_blocking_pids nem pg_terminate_backend, o YugabyteDB guarda seus locks em outro lugar). Os bancos de dados sem SQL (MongoDB, Redis, Elasticsearch, Cassandra) também não têm editor de tabelas, diagrama ER, comparação de schemas, query builder, importação de SQL, snapshots antes de alterações nem planos de consulta; as páginas deles dizem o que têm no lugar.

Todo banco de dados recebe o editor, a grade e o navegador. As linhas da grade são encontradas pela chave primária da tabela, por uma chave única em colunas não nulas, ou por uma chave virtual que você define.

Drivers baixados no primeiro uso

PostgreSQL, MySQL, SQL Server, SQLite, libSQL, ClickHouse, MongoDB, Redis, Elasticsearch e Cassandra são embutidos no app. Os outros precisam de uma biblioteca que o app baixa uma vez:

Banco de dadosO que é baixadoDe onde
DuckDBA biblioteca do DuckDB, 2.0.0A release do DuckDB no GitHub
OracleOracle Instant Client, Basic Light 23.26.4 (Windows, Linux; não macOS)Oracle
IBM Db2IBM Data Server Driver for ODBC and CLI 12.1.4 (Windows)IBM
Snowflake, BigQuery, Databricks, Trinoo driver ADBC deleso registry de drivers dbc (Columnar)

Ao escolher o banco de dados de uma nova conexão, se a biblioteca não está neste computador, um popup se abre sobre o formulário dizendo o que ela é, a versão e o tamanho, a licença e de onde vem, e que o download é verificado com um SHA-256. Baixar a obtém (o Windows pede permissão de administrador para registrar o driver da IBM); Cancelar deixa o formulário utilizável. A oferta volta em Testar conexão e na primeira abertura. A verificação lê só este computador, então aparece offline, e o download precisa de rede. Configurações › Drivers lista, atualiza e remove o que foi baixado.

Versões

A versão mais antiga com que cada banco de dados é verificado, e em que a suíte de conformidade roda (docker/compose.yml e o perfil versions). Um servidor mais antigo que o mínimo conecta com um aviso de que alguns recursos podem não funcionar, exceto Cassandra, ScyllaDB, Elasticsearch e OpenSearch, que o recusam.

Agentes

Agentes e a CLI funciona em todos os bancos de dados acima. As diferenças estão em cada página: como uma sessão somente leitura é feita (o servidor recusa gravações no PostgreSQL, CockroachDB, YugabyteDB, MySQL, MariaDB, SQLite, DuckDB e ClickHouse; em todos os outros, só a verificação da instrução), e o que é recusado (explain no MongoDB, Redis, Elasticsearch e Cassandra; get_er_diagram no MongoDB, Redis e Elasticsearch; propose_edits onde quer que a grade não edite linhas por chave: Redis, Elasticsearch, Cassandra, ClickHouse e os bancos de dados ADBC; no MongoDB ele nomeia os documentos por _id). server_activity e top_queries funcionam no PostgreSQL, MySQL, MariaDB e SQL Server.
