各数据库的支持情况

“行”指在表格中编辑。“管理”指服务器活动…的服务器标签页（会话、锁、仪表板、成本最高的语句、表和索引、参数、用户和角色、维护）。短横线表示“不可用”；“未测试”表示应用不阻止它，但没有任何测试运行过它。

数据库默认端口手动提交取消执行计划行管理
PostgreSQL5432是是计划、分析是全部
CockroachDB、YugabyteDB26257、5433是是计划、分析是–
MySQL、MariaDB3306是是计划；MySQL 8.0.18+ 和 MariaDB 支持分析是全部
SQL Server1433是是预估计划是全部；可结束会话，不能取消他人的语句
Oracle1521是是预估计划是–
ClickHouse8123（使用 TLS 时 8443）–是计划–参数、仪表板、用户
SQLite文件是是查询计划是参数
DuckDB文件是是计划、分析是参数
libSQL、Turso443（不使用 TLS 时 80）是–查询计划是–
MongoDB27017–是–––
Redis6379仅 MULTI/EXEC是–是–
Elasticsearch、OpenSearch9200–是–是–
Cassandra、ScyllaDB9042–是–是，按完整主键–
Snowflake、BigQuery、Databricks、Trino见该页面–是–––
Db2、其他 ODBCDb2 为 50000是是–未测试–

CockroachDB 和 YugabyteDB 的“管理”是关闭的，因为这些服务器缺少这些标签页所调用的部分功能（CockroachDB 没有 pg_blocking_pids 或 pg_terminate_backend，YugabyteDB 把锁放在别处）。没有 SQL 的数据库（MongoDB、Redis、Elasticsearch、Cassandra）也没有表编辑器、ER 图、模式比较、查询构建器、SQL 导入、变更前快照或查询计划；它们的页面会说明它们有什么来代替。

每种数据库都有编辑器、表格和导航器。表格中的行通过表的主键、非空列上的唯一键，或你设置的虚拟键来定位。

首次使用时下载的驱动

PostgreSQL、MySQL、SQL Server、SQLite、libSQL、ClickHouse、MongoDB、Redis、Elasticsearch 和 Cassandra 内置在应用中。其他的需要一个库，应用会下载一次：

数据库下载的内容来源
DuckDBDuckDB 的库，2.0.0DuckDB 在 GitHub 上的发布版
OracleOracle Instant Client，Basic Light 23.26.4（Windows、Linux；不含 macOS）Oracle
IBM Db2IBM Data Server Driver for ODBC and CLI 12.1.4（Windows）IBM
Snowflake、BigQuery、Databricks、Trino它们的 ADBC 驱动dbc 驱动注册表（Columnar）

选择数据库创建新连接时，如果这台机器上没有该库，表单上方会弹出一个窗口，说明它是什么、它的版本和大小、它的许可证和来源，以及下载会用 SHA-256 校验。下载会获取它（Windows 会要求管理员权限来注册 IBM 的驱动）；取消则表单仍可使用。在测试连接时和第一次打开时会再次提示。检查只读取这台机器，所以离线时也会出现，而下载需要网络。设置 › 驱动会列出、更新和移除已下载的内容。

版本

每种数据库所检查的最低版本，以及一致性测试套件所运行的版本（docker/compose.yml 和 versions 配置）。低于最低版本的服务器在连接时会给出警告，提示某些功能可能无法工作，Cassandra、ScyllaDB、Elasticsearch 和 OpenSearch 除外，它们会拒绝连接。

代理

代理和 CLI适用于上面的每一种数据库。差异见各页面：只读会话是如何建立的（在 PostgreSQL、CockroachDB、YugabyteDB、MySQL、MariaDB、SQLite、DuckDB 和 ClickHouse 上由服务器拒绝写入；其他地方只靠语句检查），以及哪些会被拒绝（MongoDB、Redis、Elasticsearch 和 Cassandra 上的 explain；MongoDB、Redis 和 Elasticsearch 上的 get_er_diagram；凡是表格不按键编辑行的地方的 propose_edits：Redis、Elasticsearch、Cassandra、ClickHouse 和 ADBC 数据库；在 MongoDB 上它按 _id 指明文档）。server_activity 和 top_queries 适用于 PostgreSQL、MySQL、MariaDB 和 SQL Server。
