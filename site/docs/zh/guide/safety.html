安全工作：生产环境、只读、确认、遮蔽

这里的所有内容也在 FEATURES.md 中。

将连接标记为生产环境

  1. 编辑连接，打开外观与安全页面。
  2. 把环境设为生产（其他选项是开发和测试）。生产环境在更改前会询问，并以手动提交模式启动。
  3. 可以选一种颜色，方便区分这个连接。

此后，该连接上的每处更改都会列在一个标题为“<name> 上的更改（生产）”的对话框中，附带相应语句，确认之后才会运行。设置（Ctrl+,）› 安全 › 在生产连接上修改前询问可以在整个应用中关闭这一行为。代理在生产连接上最多只能是只读。

将连接设为只读

  1. 在同一页面，勾选只读（拒绝修改数据）。
  2. 可能修改数据的语句不会运行。编辑器显示“<name> 是只读的，而此操作可能会修改数据。”，且无法绕过。以下情形同样如此：带分析的执行计划（“此语句可能会修改数据。”）、用 @include 引入的文件、笔记本单元格（“此单元格可能更改数据。”）、命令行客户端，以及在多个连接上运行，后者会把该连接列为已跳过（“只读连接”）。
  3. 完全不提供的功能：导入数据…、将数据导入新表…、将 CSV 粘贴为新表…、生成数据…、运行 SQL 文件…、创建对象、在表设计器中保存，以及在表格中编辑行。代理仍然只读。

编辑器标签页的锁定按钮只让该标签页只读，而不改动已保存的连接。这是唯一会询问的情形：编辑器显示同样的消息，并带有一个仍然运行按钮，命令行客户端则询问 "Run anyway?"。

同一页面还有两个复选框：禁止导出（其数据不会写入任何文件、其他数据库或代理）和禁止编辑数据（行只能通过 SQL 修改，不能在表格、导入或生成的数据中修改）。

确认

设置 › 安全 › 更改之前：

  • 不带 WHERE 的 UPDATE 或 DELETE（也包括 TRUNCATE）：运行前询问（默认）、从不运行或直接运行。对话框询问“修改每一行？”，并说明大约有多少行。
  • 事务保持打开超过多久时提醒（分钟）：默认 10，0 表示从不提醒。
  • 为没有 LIMIT 的查询添加 LIMIT（行数）：0（默认）表示从不添加。
  • 代理更改数据前先询问：见代理。

撤销更改

默认开启的保留 UPDATE 或 DELETE 将要修改的行，以便恢复（设置 › 安全 › 锁定和备份）会保留从编辑器运行的、针对一张表的 UPDATE 或 DELETE 所修改的行，最多 10,000 行。打开编辑器工具栏中的事务日志并点击恢复…，或从命令面板运行变更前快照…，即可得到把这些行恢复原状的脚本。

遮蔽敏感数据

  1. 按 Ctrl+Alt+M（或从命令面板运行遮蔽敏感数据）：共享屏幕时，敏感列的值显示为圆点。复制时保留真实的值。
  2. 设置 › 安全 › 遮蔽按名称设置哪些列是敏感列（默认有 *password*、*token*、*email* 等；* 代表任意字符），也可以按类型设置。你还可以在表的标签页中标记某一列。

代理读取到的敏感列同样是被遮蔽的，除非你在设置 › 代理 › 安全中为该连接勾选向代理显示敏感列的值。MongoDB 文档内的敏感字段（user.password）同样会被遮蔽。当代理询问你正在处理什么时，以其他名称读取的列（SELECT email AS contact）同样会被遮蔽；如果语句把它藏在子查询后面，整个共享的结果都会被遮蔽。

在应用之外移除的规则或标记（例如带文件工具的代理编辑 settings.toml 或 catalog.db），在你接受之前不会对代理生效：应用会询问，设置 › 代理 › 安全会列出它，并提供接受或撤销的方式。在应用之外新增的规则则立即生效。这只涵盖对这些文件的编辑，仅此而已。能以你的用户身份运行命令的代理可以通过其他途径读取数据库，或读取存放密封信息的系统钥匙串：要防止这样的代理看到这些值，请以另一个用户运行它，并为连接配置一个无权访问这些列的数据库用户。

答复只对问题列出的内容有效：如果文件在询问期间再次变化，点击接受更改不会接受任何内容，并会重新显示列表。

锁定应用

设置了主密码时（见连接），设置 › 安全 › 空闲多少分钟后锁定应用（0，即默认值，表示从不锁定）会锁定 PlatypusDB 并关闭生产连接。命令面板中的锁定 PlatypusDB会立即锁定。输入主密码即可解锁：生产连接在使用时会重新连接。
