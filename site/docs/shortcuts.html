Keyboard shortcuts

On macOS use Cmd instead of Ctrl. Every shortcut can be changed in Settings › Keyboard shortcuts.

On keyboards that type a character with Shift (/ is Shift+7 on Italian and German ones) the shortcut takes Shift too: Ctrl+/ is Ctrl+Shift+7 there. AltGr always types its character: Windows reports it as Ctrl+Alt, so Ctrl+Alt with a symbol ([, @, {, \...) is never a shortcut outside macOS.
