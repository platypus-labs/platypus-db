"Admin" on CockroachDB and YugabyteDB is off because those servers lack parts of what the tabs call (CockroachDB has no pg_blocking_pids or pg_terminate_backend, YugabyteDB keeps its locks elsewhere). The databases with no SQL (MongoDB, Redis, Elasticsearch, Cassandra) also have no table editor, ER diagram, schema comparison, query builder, SQL import, snapshots before changes or query plans; their pages say what they have instead.

Every database gets the editor, the grid and the navigator. Rows in the grid are found by the table's primary key, a unique key on non-null columns, or a virtual key you set.

Drivers downloaded on first use

PostgreSQL, MySQL, SQL Server, SQLite, libSQL, ClickHouse, MongoDB, Redis, Elasticsearch and Cassandra are built into the app. The others need a library that the app downloads once:

DatabaseWhat is downloadedFrom
DuckDBDuckDB's library, 2.0.0DuckDB's release on GitHub
OracleOracle Instant Client, Basic Light 23.26.4 (Windows, Linux; not macOS)Oracle
IBM Db2IBM Data Server Driver for ODBC and CLI 12.1.4 (Windows)IBM
Snowflake, BigQuery, Databricks, Trinotheir ADBC driverthe dbc driver registry (Columnar)

When you pick the database for a new connection, and the library is not on this machine, a popup opens over the form that says what it is, its version and size, its license and where it comes from, and that the download is checked against a SHA-256. Download fetches it (Windows asks for administrator permission to register IBM's driver); Cancel leaves the form usable. The offer returns at Test connection and at the first opening. The check reads only this machine, so it appears offline, and the download needs the network. Settings › Drivers lists, updates and removes what was downloaded.

Agents

Agents and the CLI works on every database above. The differences are on each page: how a read-only session is made (the server refuses writes on PostgreSQL, CockroachDB, YugabyteDB, MySQL, MariaDB, SQLite, DuckDB and ClickHouse; everywhere else the statement check alone), and what is refused (explain on MongoDB, Redis, Elasticsearch and Cassandra; get_er_diagram on MongoDB, Redis and Elasticsearch; propose_edits wherever the grid does not edit rows by key: Redis, Elasticsearch, Cassandra, ClickHouse and the ADBC databases; on MongoDB it names documents by _id). server_activity and top_queries work on PostgreSQL, MySQL, MariaDB and SQL Server.
