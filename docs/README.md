# Documentation

## For users: [user/](user/)

| Document | What it covers |
|---|---|
| [guide/](user/guide/README.md) | The user guide, by task: getting started, connecting, queries, editing data, import and export, safety, projects, agents, troubleshooting, and [a page per database](user/guide/databases/README.md). The app carries it, under Help |
