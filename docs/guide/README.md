# User guide

Short pages, each a task to follow step by step. [FEATURES.md](../FEATURES.md) stays the
reference, area by area; these pages link to it for the details.

| I want to | Page |
|---|---|
| Install PlatypusDB and open my first connection | [Getting started](getting-started.md) |
| Connect to a database: URL, SSH tunnel, TLS, saved passwords | [Connect](connect.md) |
| Connect to one particular database (driver, port, URL, quirks) | [Databases](databases/README.md) |
| Run SQL and read the results | [Queries](queries.md) |
| Change rows in the grid | [Edit data](edit-data.md) |
| Load a file into a table, or send a table to a file or another database | [Import and export](import-export.md) |
| Work on production without accidents | [Safety](safety.md) |
| Organize connections in projects, share a query or a project with a colleague | [Projects and sharing](projects-sharing.md) |
| Let Claude Code, Codex or another agent use my connections | [Agents](agents.md) |
| Fix a connection, a driver download, an agent or an update | [Troubleshooting and FAQ](troubleshooting.md) |

Keys are in [SHORTCUTS.md](../SHORTCUTS.md); on macOS use `Cmd` instead of `Ctrl`.
