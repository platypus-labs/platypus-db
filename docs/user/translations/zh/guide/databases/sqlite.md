# SQLite

SQLite 在应用内部运行（`rusqlite`，内置 SQLite）：没有服务器、主机、用户和密码，也无需下载任何东西。

## 连接

选择 **SQLite** 并给出文件路径，或粘贴 URL：

| 你粘贴的内容 | 含义 |
|---|---|
| `sqlite:///home/ana/app.db` | 文件 `/home/ana/app.db` |
| `sqlite:///C:/data/app.db` | Windows 盘上的文件 |
| `sqlite:///:memory:` | 内存数据库 |
| 路径字段中的 `file:app.db?mode=ro` | SQLite URI，原样传给 SQLite |

如果文件不存在但其文件夹存在，会作为空数据库创建该文件。文件夹不存在是错误（更可能是拼写错误或磁盘没有挂载），不存在的相对路径也是错误：请给出完整路径。不是 SQLite 数据库的文件在连接时会被拒绝。

只读连接（以及只读代理）以只读方式打开文件，因此由 SQLite 本身拒绝写入。SSL、SSH 和代理设置不适用于嵌入式数据库。

## 权限

由操作系统决定：应用需要读取该文件，并且需要写入该文件及其文件夹（用于日志）才能更改任何内容。遇到忙碌的文件会先等待，然后才报错。

## 可用功能

- 在表格中按主键（或非空列上的唯一键，或虚拟键）编辑数据。`INTEGER PRIMARY KEY` 列算作键，尽管 SQLite 报告它可为空。
- 手动提交和回滚；取消正在运行的语句（`sqlite3_interrupt`）。
- 执行计划只显示 SQLite 的查询计划：没有分析执行计划。
- 参数标签页：重要的 pragma，附带 SQLite 文档记载的默认值。
- 没有会话、锁、仪表板、用户或语句标签页。
- 表编辑器、ER 图和比较。SQLite 很少能就地修改，所以更改表会重新创建它并复制其行；比较和重建会保留表达式索引和部分索引、延迟键以及 `AUTOINCREMENT` 计数器。
- 元数据搜索、对象 DDL，以及与任何 SQL 数据库一样的导出、导入和复制。
- 终端模式运行 `sqlite3`（如果它在 PATH 中）。

## 代理

只读代理和只读连接以只读方式打开文件，并用 `query_only` 运行它们的查询。`estimate_change` 在 SQLite 上无法给出行数估计。见[代理和 CLI](../../AGENTS.md)。

## 已知限制

- 可能有另一个进程占用着该文件：应用会等待忙碌的文件最多 5 秒，然后 SQLite 报告错误。
- 代理调用 `load_extension(…)` 的语句会像更改一样先询问。

## 测试环境

一致性测试套件在应用内置的 SQLite 上运行，包括事务、计划、表编辑、保留 `AUTOINCREMENT` 的重建，以及以只读方式打开的文件。
