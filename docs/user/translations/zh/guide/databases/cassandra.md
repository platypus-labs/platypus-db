# Apache Cassandra 和 ScyllaDB

一个基于 `scylla` crate（使用 rustls）的驱动，通过原生协议用 CQL 与两者通信。服务器会说明它是哪一种，连接中会显示出来。驱动是应用的一部分，无需下载任何东西。编辑器接受 CQL。

## 连接

| 你粘贴的内容 | 解读为 |
|---|---|
| `cassandra://cassandra:s%40cret@node1:9043/shop` | 明文，端口 9043，键空间 `shop` |
| `scylla://node1` | 同一个驱动，用于 ScyllaDB |
| `cassandras://…` 和 `scyllas://…` | 使用 TLS（经过验证：`verify-full`） |

默认端口是 9042。**主机**字段是一个联系点，或用逗号分隔的多个 `host:port`。**键空间（可选）**字段是会话起始所在的键空间；无论是否填写，导航器都会列出所有键空间。

- **一个联系点，或隧道**：该节点独自处理每条语句。集群会公布各节点自己的地址，而容器、NAT 或隧道会隐藏这些地址，所以驱动不会去跟随它们。有多个联系点时，驱动会拿到全部联系点，可以使用其中任何一个。
- **登录**：用户和密码，用于服务器的密码认证器。没有用户时，连接是匿名的。
- **TLS**：CQL 无法协商它，所以对 `cassandras://` 和 `scyllas://` URL，以及从 `require` 起的 SSL 模式，TLS 都是开启的；`prefer` 是明文。`require` 不检查证书；`verify-ca` 和 `verify-full` 会检查。CA 文件和客户端证书填在 TLS 字段中。
- **语句没有驱动自己的超时**：语句会一直运行到结束，或由你取消。

## 权限

导航器读取 `system_schema`，Cassandra 3 及更高版本和 ScyllaDB 共用它；该登录能看到服务器允许它在那里读取的内容。没有管理标签页。写入需要 CQL 所要求的权限。

## 可用功能

- 由编辑器拆分的 CQL 脚本（能识别 `$$ … $$` 字符串、`//` 注释和 `BEGIN BATCH … APPLY BATCH`），带类型的结果在你滚动时使用服务器的分页状态逐页读取。
- 导航器：键空间作为模式、表、物化视图、用户定义类型、函数和聚合，以及每张表的分区键和聚簇键及其索引；每个对象的 DDL。
- **表格可以编辑行**，按完整主键（分区列和聚簇列）：编辑过的行是 `UPDATE`，新行是需要每个键列的 `INSERT`，删除的行是 `DELETE`。预览显示这些语句，它们会依次运行；服务器拒绝其中一条时，其余的会停止。*撤销脚本*会恢复旧值。键列不能更改（请删除该行并插入另一行），计数器会被拒绝。
- 轻量级事务（`IF …`）会作为轻量级事务报告并附上结果。
- 取消会停止正在读取的结果。错误保留服务器的消息。
- `USE keyspace` 会更改会话的键空间，驱动会记住它。

## 不可用功能

- **没有事务**：每条语句单独生效，也没有手动提交。
- **CQL 写入是 upsert，不报告行数**，所以不返回行的语句报告没有更改；对期间被别人删除的行执行更新会重新写入它。
- 数据查看器没有过滤和排序栏，也不显示行数。
- 没有执行计划，也没有 SQL 工具：没有表编辑器、ER 图、模式比较、查询构建器、SQL 导入、变更前快照或终端模式（`cqlsh` 只在命令行上接受密码）。

## 代理

`run_query` 和 `sample_rows`（CQL 的 `SELECT … LIMIT n`）可用；修改数据的语句会先询问。在 Cassandra 上被拒绝的有：`explain` 和 `propose_edits`；`estimate_change` 会以一条说明作答。见[代理和 CLI](../../../../AGENTS.md)。

## 已知限制

- 低于 4.0 的 Cassandra 和低于 5.4 的 ScyllaDB 在连接时会被拒绝，并提示 "older than … the oldest version supported"，这与会带警告连接的其他数据库不同。
- 没有连接（join），没有 `OFFSET`，行只能通过主键找到，这是 CQL 的规则。

## 测试环境

一致性测试套件在 Apache Cassandra 5 和 ScyllaDB 2025.1 上运行，不带登录：服务器信息、脚本、每种类型作为带类型的列、分页、轻量级事务、错误、取消、目录及其 DDL（也包括函数和聚合）、保存表格的更改并撤销、错误或缺失的登录被拒绝，以及隧道地址。Cassandra 4.0 和 ScyllaDB 5.4 是驱动接受的最低版本，测试套件没有运行它们。
