# Snowflake、BigQuery、Databricks、Trino 和其他 ADBC 驱动

这些数据库通过 **ADBC**（Arrow Database Connectivity）驱动连接，这些驱动是应用在连接时加载的库。Snowflake、BigQuery、Databricks 和 Trino 各有一个图块；任何其他带 ADBC 驱动的数据库都通过**其他 ADBC 驱动**连接。

## 首次使用：驱动下载

这四个指名的数据库需要在这台机器上有它们的驱动。当你为新连接选择其中一个，而驱动尚未安装时，表单上方会弹出一个窗口：*Snowflake 需要驱动*（其他类推）。它说明这是一个 ADBC 驱动，该数据库的所有连接共用一份、只下载一次，并显示软件包、版本、许可证和来源：[dbc 驱动注册表](https://docs.columnar.tech/dbc/)（Columnar）。**下载**会获取它，校验其 SHA-256（没有 SHA-256 的软件包会被拒绝），并把它保存在应用的数据中；**取消**则表单仍可使用，并在*测试连接*时和第一次打开时再次提示。

该提示只读取这台机器上的内容，所以离线时也会出现；下载需要网络。*设置 › 驱动*会列出已安装的驱动并可移除它们，每天检查一次是否有更新的版本（或在点击*检查更新*时检查），用*版本…*安装或回退到另一个版本，还可以自动安装更新。更改之后，会试用使用该驱动的已保存连接（连接、版本、模式、`SELECT 1`），如果有失败的，可以*回退*。选择其他驱动时不下载任何内容：你自己指向一个库文件。

## 连接

每种数据库有各自的字段：

| 数据库 | 字段 |
|---|---|
| Snowflake | **账户**（例如 `xy12345.eu-west-1`）、用户、密码、仓库、角色、数据库、模式 |
| BigQuery | **项目**、数据集，以及服务账号密钥文件（JSON）；留空表示使用 Google 的 Application Default Credentials。没有密码 |
| Databricks | **服务器主机名**、**HTTP 路径**、目录、模式；密码字段是**访问令牌** |
| Trino | **主机**、端口（默认 8080）、**用户**、目录、模式、密码（可选）和 TLS |
| 其他 ADBC 驱动 | **驱动库**文件、可选的**入口函数**符号、URI、用户和密码；你添加的所有其他选项都会传给驱动 |

**Trino 的 TLS** 选项有*自动*（端口 443 上用 HTTPS，否则用 HTTP）、*关闭*（HTTP）、*开启 — HTTPS，验证证书*和*开启 — HTTPS，不验证*。

**其他 ADBC 驱动**：库是你下载或构建的驱动文件。只有不导出 `AdbcDriverInit` 的库才需要入口函数（对 DuckDB 的 ADBC 库，它是 `duckdb_adbc_init`）。URI 和选项以该驱动的文档为准。文件不存在或不是驱动，会在连接时报告。

## 权限

由账户或令牌在该服务上拥有的权限决定。导航器通过 ADBC 的元数据调用读取目录、模式、表和列。

## 可用功能

- 查询、结果、导航器和自动补全。结果以 Arrow 批次流式传输。
- 取消：应用请求驱动取消；基于 Go 的驱动只会取消它们自己的调用，所以不停止的语句会连同其会话一起被放弃，应用会打开一个新的会话。
- 仅 **Trino** 有对象 DDL（`SHOW CREATE`）。Snowflake、BigQuery、Databricks 和其他驱动不显示 DDL。
- 指向某张表的外键不会列出（那意味着要读取每张表的键）。
- 导出，以及文件导入（带类型的导入在 Trino 上测试过）。

## 不可用功能

- **没有手动提交**：每条语句自动提交，关闭自动提交时会提示 ADBC 驱动不支持手动提交。
- **没有执行计划**，也没有管理标签页。
- **不能在表格中编辑数据**：保存需要在事务中检查每处更改，而这些连接没有事务。结果保持只读；请用 SQL 修改。
- 终端模式不可用。

## 代理

`run_query`、`sample_rows` 和其他工具可用，受各项检查约束。没有服务器端的只读会话，只读代理只依靠语句检查。在其之外起作用的语句会在运行前先询问：Trino 的 `query()` 和 Snowflake 的 `SYSTEM$` 函数。见[代理和 CLI](../../../../AGENTS.md)。

## 已知限制

- 上述字段之外的云仓库登录方式（密钥对、单点登录）不在表单中；通用驱动接受驱动自己的选项。
- Snowflake、BigQuery 和 Databricks 在代码中，与 Trino 共用驱动层，但没有针对真实服务的测试。

## 测试环境

一致性测试套件通过下载的驱动运行 **Trino 484**（类型、长结果、取消、元数据、错误、以终止符结尾的语句、带类型的导入，以及行和 UUID），并在 Apache SQLite ADBC 驱动和 DuckDB 的 ADBC 驱动上运行**通用 ADBC 驱动**。Snowflake、BigQuery 和 Databricks 没有测试。

另见：[连接](../connect.md)、[故障排除](../troubleshooting.md)。
