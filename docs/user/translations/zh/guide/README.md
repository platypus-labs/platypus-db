# 用户指南

简短的页面，每页是一项可以一步步照做的任务。[FEATURES.md](../FEATURES.md) 仍是按功能区域编排的参考文档；这些页面会链接到它以获取详细说明。

| 我想要 | 页面 |
|---|---|
| 安装 PlatypusDB 并打开第一个连接 | [快速入门](getting-started.md) |
| 连接数据库：URL、SSH 隧道、TLS、已保存的密码 | [连接](connect.md) |
| 连接某个特定的数据库（驱动、端口、URL、注意事项） | [数据库](databases/README.md) |
| 运行 SQL 并查看结果 | [查询](queries.md) |
| 在表格中修改行 | [编辑数据](edit-data.md) |
| 将文件载入表，或将表发送到文件或另一个数据库 | [导入和导出](import-export.md) |
| 在生产环境中工作而不出意外 | [安全](safety.md) |
| 用项目整理连接，与同事共享查询或项目 | [项目与共享](projects-sharing.md) |
| 让 Claude Code、Codex 或其他代理使用我的连接 | [代理](agents.md) |
| 修复连接、驱动下载、代理或更新问题 | [故障排除与常见问题](troubleshooting.md) |

快捷键见 [SHORTCUTS.md](../SHORTCUTS.md)；在 macOS 上用 `Cmd` 代替 `Ctrl`。
