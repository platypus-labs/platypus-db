# 导入和导出

下面的操作都在导航器的右键菜单和命令面板（`Ctrl+K`）中。格式和选项的完整列表见 [FEATURES.md](../FEATURES.md#import-export-and-transfer)。

## 将文件导入表

![待导入文件的预览](../../screenshots/guide/import-preview.png)

1. 在导航器中右键点击表，然后选择**数据** › **导入数据…**。
2. 选择文件：CSV、TSV、JSON、NDJSON、Parquet 或 Excel。
3. 检查预览和列的映射。
4. 选择**添加这些行**、**替换所有行**或**更新键相同的行，添加其他行**，然后点击**导入**。最后一项需要表上有主键，且 ClickHouse 不提供。

**导入数据…**适用于表，不适用于视图。要导入到新表，请右键点击模式并选择**将数据导入新表…**：类型由 DuckDB 根据文件推断，且不能选择导入方式。**将 CSV 粘贴为新表…**（同一菜单）会导入剪贴板的内容。

在只读连接、禁止编辑数据的连接以及 NoSQL 数据库上不提供导入。

## 将表导出到文件

1. 右键点击一张表，或选中多张表，然后选择**数据** › **导出数据…**。要导出某个模式的所有表，请右键点击该模式并选择**导出所有表…**。
2. 选择**格式化**（CSV、JSON、NDJSON、Parquet、Excel、SQL `INSERT`、Markdown、HTML 或 XML），然后点击**导出到文件夹…**：即使只有一张表，应用也会要求选择文件夹，并为每张表写入一个以其命名的文件。
3. 可以设置**压缩**（gzip 或 zstd；Parquet 和 Excel 不适用，它们本身已经压缩），以及**同时上传到…**存储桶（S3、GCS、R2 或 MinIO）。

当你导出的是查询结果（结果表格的导出）时，对话框要求选择一个文件，上传还可以发送到签名 URL（S3 或 GCS）。

电子表格会当作公式执行的 CSV 单元格，会在开头加上 `'`，除非你关闭**公式按文本写入（用于电子表格）**。连接可以禁止导出（**外观与安全**页面）；此时不提供这项操作。见[安全](safety.md)。

要取出查询的结果，可以从表格中把它复制为 CSV、JSON、Markdown、HTML、SQL `INSERT` 或 `IN` 列表。

## 将表或模式复制到另一个数据库

右键点击一张表并选择**数据** › **复制到数据库…**（可以映射列），选中某个模式的多张表并选择**数据** › **将表复制到数据库…**，或右键点击模式并选择**将模式复制到数据库…**。类型会被映射。目标是一个不是只读、且允许编辑数据的 SQL 连接。复制多张表或整个模式仅适用于 SQL 数据源；一个 MongoDB 集合或一种 Redis 键类型可以复制到 SQL 数据库。当连接禁止导出时，这些操作都不提供。

## 运行 SQL 文件，或转储为 SQL 文件

右键点击连接或数据库并选择**运行 SQL 文件…**：它会逐条语句运行任意大小的 `.sql` 文件（或 `.sql.gz`、`.sql.zst`），带进度和停止按钮，默认放在一个事务中，失败时回滚。**转储到 SQL 文件…**（在模式上，或在**数据**下的表上）会把模式或所选对象的 DDL，以及需要时它们的行，写入一个文件。

## 保存传输以便以后使用

每个导出、导入和复制对话框都有**另存为配置…**。**传输配置…**（命令面板）可以运行、重命名、删除和调度它们。存储桶的密钥绝不会保存到配置文件中。

## 不导入也能查询数据文件

把 CSV、JSON、Parquet 或 Excel 文件拖到窗口上，或点击欢迎界面上的**打开数据文件**：它会作为数据库打开（每个 Excel 工作表是一张表）。第一次时，应用会提示下载 DuckDB 的库。

## 导入连接

在欢迎界面，**导入连接**可以读取 DBeaver、DataGrip 和 pgAdmin（以及 `pg_service.conf`）；DBeaver 和 DataGrip 的 Db2 连接以及 `jdbc:db2:` URL 也能读取。**导出连接**会写出一个 `.platypusconn` 文件，供另一台电脑使用：见[项目与共享](projects-sharing.md)。
