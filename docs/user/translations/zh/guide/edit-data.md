# 编辑数据

![数据编辑器中的待保存更改](../../screenshots/data-editor.png)

## 在表格中修改行

1. 在导航器中打开表，或运行一个只读取一张表的查询。
2. 双击单元格、按 `F2` 或直接输入即可修改。`Shift+Delete` 将选中的单元格设为 NULL。
3. `Insert` 添加一行，`Ctrl+D` 复制选中的行，`Delete` 删除它。
4. 在保存之前，更改会一直高亮显示。用**预览 SQL** 查看将执行的语句。
5. 按 `Ctrl+S`（或**保存更改**）保存全部更改；如果其中一条失败，则全部不保存。`Ctrl+Z` 撤销尚未保存的更改。

每次保存都会留下一个撤销脚本，可以把这些行恢复原状。在手动提交模式下，更改会加入当前打开的事务。

## 表格为只读时

表需要有主键，或在非空列上的唯一键，或你选择的虚拟键；否则表格会说明为什么无法编辑。连接也可以禁止编辑数据（其设置的**外观与安全**页面）：此时只能用 SQL 修改行。

## 无需 SQL 编辑文档、键和行

Redis、Elasticsearch、Cassandra 和 MongoDB 的结果同样可以编辑，使用它们自己的命令而不是 SQL：**预览 SQL** 会显示这些命令。在 MongoDB 上，对单个集合执行普通 `find` 的结果可以按 `_id` 编辑。每处更改对应一次 `updateOne`、`insertOne` 或 `deleteOne`，并按该列的 BSON 类型书写；如果文档存储的数值类型能精确容纳修改后的数字，就保持该数值类型。编辑 `_id`、混合类型的列以及名称中带 `.` 的字段会被拒绝，并说明原因。在副本集上，保存要么全部成功要么全部不保存；在独立服务器上，命令逐条执行，错误信息会说明已保存了多少条。见 [MongoDB](databases/mongodb.md#在表格中编辑文档)。

## 一次编辑多个单元格

选中单元格，使用表格菜单中的**编辑选中内容**：给每个单元格填入一个值、NULL 或 DEFAULT，在文本单元格中查找和替换，或填入数字序列。`Ctrl+Alt+D` 从第一行开始向下填充（macOS 上为 `⌃⇧D`）。只有表格中已加载的行会被修改，结果是待保存的更改，可以一起预览、保存或撤销。

用 `Ctrl+V` 把电子表格的内容粘贴到单元格上，或用 `Ctrl+Shift+V` 粘贴为新行。

## 将文件载入单元格

从表格菜单，或单元格编辑器的 `…` 按钮：字节写入二进制列，UTF-8 文本写入文本列。超过 50 MB 的文件会先询问；超过 200 MB 的文件会被拒绝。

## 代理提议的行

当代理调用 `propose_edits` 时，表会在其数据查看器中打开，提议的行作为待保存的更改显示，颜色与你自己的更改相同。在你保存之前不会写入任何内容；丢弃它们即为拒绝。见[代理](agents.md)。
