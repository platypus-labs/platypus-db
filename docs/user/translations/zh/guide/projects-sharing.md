# 项目与共享

项目是一组连接、脚本和打开的标签页，显示在左侧的栏中。详细信息见 [FEATURES.md](../../../FEATURES.md#workspace) 和 [FEATURES.md](../../../FEATURES.md#sharing-and-sync)。

## 创建项目

1. 在命令面板（`Ctrl+K`）中运行**新建项目…**。
2. 给它起名，然后选择要在其中显示的连接。也可以从连接自己的表单添加：**外观与安全**页面末尾的**项目**。
3. `Ctrl+1` 显示所有连接，`Ctrl+2` 到 `Ctrl+9` 按栏中的顺序显示各个项目。

## 分享查询

1. 在 SQL 编辑器标签页中，运行**分享查询…**（标签页菜单或命令面板）。
2. 复制 `platypus://…` 链接，或保存一个 `.platypus` 文件。它包含 SQL、标题，以及（如果你要求）参数值；它会写出数据库的名称，但绝不包含密码。
3. 同事用**打开共享链接…**或**打开共享查询…**打开它，或把文件拖到窗口上。应用会找到匹配的已保存连接，或提供一个填好的新连接，并显示查询但不运行它。

## 与团队共享项目

1. 在栏中右键点击项目并选择**共享项目…**，然后选一个团队存放在 Git 中或共享盘上的文件夹。其中保存连接（不含凭据）和脚本。
2. 每位同事在欢迎界面点击**打开共享项目…**，选择该文件夹，并输入自己的密码。
3. 文件夹发生变化后，从项目菜单运行**重新读取共享文件夹**。

设计上就是安全的：来自共享项目的新连接，在你的电脑上默认不给代理**任何访问权限**，直到你另行选择；文件在每次连接时运行的语句会先显示出来，只有在你批准那段确切的文本之后才会运行。

## 将连接带到另一台电脑

在欢迎界面，**导出连接**会写出一个 `.platypusconn` 文件：选择连接，并可选择设置至少 8 个字符的密码，它会加密文件，并让文件可以携带已保存的密码。在另一台电脑上，用**导入连接**读取它。没有密码时，文件不含任何凭据。

要让设置、连接和脚本在你的各台电脑之间保持同步，请使用设置 › **同步**，并选择云盘中的文件夹。见 [FEATURES.md](../../../FEATURES.md#sharing-and-sync)。

## 脚本和 Git

当项目的脚本文件夹是 Git 仓库时，脚本面板会显示分支和每个脚本的更改，并提供**提交…**、**拉取**和**推送**。必须已安装 Git。
