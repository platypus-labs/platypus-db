# Benutzerhandbuch

Kurze Seiten, jede eine Aufgabe, die du Schritt für Schritt nachvollziehst. [FEATURES.md](../FEATURES.md)
bleibt die Referenz, Bereich für Bereich; diese Seiten verweisen für die Details darauf.

| Ich möchte | Seite |
|---|---|
| PlatypusDB installieren und meine erste Verbindung öffnen | [Erste Schritte](getting-started.md) |
| Mich mit einer Datenbank verbinden: URL, SSH-Tunnel, TLS, gespeicherte Passwörter | [Verbinden](connect.md) |
| Mich mit einer bestimmten Datenbank verbinden (Treiber, Port, URL, Besonderheiten) | [Datenbanken](databases/README.md) |
| SQL ausführen und die Ergebnisse lesen | [Abfragen](queries.md) |
| Zeilen im Raster ändern | [Daten bearbeiten](edit-data.md) |
| Eine Datei in eine Tabelle laden oder eine Tabelle in eine Datei oder eine andere Datenbank senden | [Import und Export](import-export.md) |
| In der Produktion ohne Unfälle arbeiten | [Sicherheit](safety.md) |
| Verbindungen in Projekten ordnen, eine Abfrage oder ein Projekt mit einer Kollegin oder einem Kollegen teilen | [Projekte und Teilen](projects-sharing.md) |
| Claude Code, Codex oder einen anderen Agenten meine Verbindungen nutzen lassen | [Agenten](agents.md) |
| Eine Verbindung, einen Treiber-Download, einen Agenten oder ein Update reparieren | [Fehlerbehebung und FAQ](troubleshooting.md) |

Die Tastenkürzel stehen in [SHORTCUTS.md](../SHORTCUTS.md); auf macOS nimmst du `Cmd` statt `Ctrl`.
