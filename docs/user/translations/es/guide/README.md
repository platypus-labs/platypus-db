# Guía del usuario

Páginas cortas, cada una una tarea para seguir paso a paso. [FEATURES.md](../FEATURES.md) sigue
siendo la referencia, área por área; estas páginas remiten a él para los detalles.

| Quiero | Página |
|---|---|
| Instalar PlatypusDB y abrir mi primera conexión | [Primeros pasos](getting-started.md) |
| Conectar a una base de datos: URL, túnel SSH, TLS, contraseñas guardadas | [Conectar](connect.md) |
| Conectar a una base de datos concreta (driver, puerto, URL, particularidades) | [Bases de datos](databases/README.md) |
| Ejecutar SQL y leer los resultados | [Consultas](queries.md) |
| Cambiar filas en la cuadrícula | [Editar datos](edit-data.md) |
| Cargar un archivo en una tabla, o enviar una tabla a un archivo o a otra base de datos | [Importar y exportar](import-export.md) |
| Trabajar en producción sin accidentes | [Seguridad](safety.md) |
| Organizar las conexiones en proyectos, compartir una consulta o un proyecto con un colega | [Proyectos y uso compartido](projects-sharing.md) |
| Dejar que Claude Code, Codex u otro agente use mis conexiones | [Agentes](agents.md) |
| Arreglar una conexión, una descarga de driver, un agente o una actualización | [Solución de problemas y preguntas frecuentes](troubleshooting.md) |

Las teclas están en [SHORTCUTS.md](../SHORTCUTS.md); en macOS usa `Cmd` en lugar de `Ctrl`.
