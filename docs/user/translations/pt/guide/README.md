# Guia do usuário

Páginas curtas, cada uma uma tarefa para seguir passo a passo. [FEATURES.md](../FEATURES.md) continua
sendo a referência, área por área; estas páginas remetem a ele para os detalhes.

| Quero | Página |
|---|---|
| Instalar o PlatypusDB e abrir minha primeira conexão | [Primeiros passos](getting-started.md) |
| Conectar a um banco de dados: URL, túnel SSH, TLS, senhas salvas | [Conectar](connect.md) |
| Conectar a um banco de dados específico (driver, porta, URL, particularidades) | [Bancos de dados](databases/README.md) |
| Executar SQL e ler os resultados | [Consultas](queries.md) |
| Alterar linhas na grade | [Editar dados](edit-data.md) |
| Carregar um arquivo em uma tabela, ou enviar uma tabela para um arquivo ou outro banco de dados | [Importar e exportar](import-export.md) |
| Trabalhar em produção sem acidentes | [Segurança](safety.md) |
| Organizar conexões em projetos, compartilhar uma consulta ou um projeto com um colega | [Projetos e compartilhamento](projects-sharing.md) |
| Deixar o Claude Code, o Codex ou outro agente usar minhas conexões | [Agentes](agents.md) |
| Resolver um problema de conexão, de download de driver, de agente ou de atualização | [Solução de problemas e FAQ](troubleshooting.md) |

Os atalhos estão em [SHORTCUTS.md](../SHORTCUTS.md); no macOS use `Cmd` no lugar de `Ctrl`.
