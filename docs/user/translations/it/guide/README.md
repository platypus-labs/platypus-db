# Guida utente

riferimento, area per area; queste pagine rimandano lì per i dettagli.

|---|---|

| Connettermi a un database in particolare (driver, porta, URL, particolarità) | [Database](databases/README.md) |

| Modificare le righe nella griglia | [Modificare i dati](edit-data.md) |

| Organizzare le connessioni in progetti, condividere una query o un progetto con un collega | [Progetti e condivisione](projects-sharing.md) |
| Far usare le mie connessioni a Claude Code, Codex o a un altro agente | [Agenti](agents.md) |
