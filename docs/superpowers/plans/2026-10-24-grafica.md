# Nuova grafica (Parte A) — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dare a PlatypusDB l'aspetto della direzione 2 ("scura e compatta", stile Linear):
nuovi temi Platypus Dark/Light, font inclusi, icone Lucide, componenti ridisegnati.

**Architecture:** I colori restano variabili CSS impostate da `theme.ts`; la `Palette`
cresce di qualche variabile, con valori derivati per i preset esistenti. Il CSS si divide per
area in `src/styles/`. Le icone passano da un solo componente `Icon`. La griglia (canvas)
legge font e colori dalle stesse variabili.

**Tech Stack:** React 19 + TypeScript, Vite, Tauri 2, CodeMirror 6, `lucide-react`, font
Inter e JetBrains Mono (OFL) in `woff2`.

**Spec:** `docs/superpowers/specs/2026-10-24-grafica-e-progetti-design.md`, Parte A.

## Global Constraints

- Branch `feat/visual-refresh` da `main`. Commit in inglese, senza nominare Claude, stile
  `feat:` / `refactor:` / `test:` come il resto della storia.
- Le classi CSS usate dagli scenari E2E **non cambiano nome né struttura**: `.shell`,
  `.workspace`, `.tabs`, `.tab`, `.query-tab`, `.object-tab`, `.tree`, `.tree-row`,
  `.tree-label`, `.tree-filter`, `.statusbar`, `.edit-bar`, `.modal`, `.palette`, `.context-menu`, `.notice`,
  `.error`, `.type-badge`, `.empty-import`, `.import-found`, `.import-list`, `.cm-content`.
- Il testo dei bottoni e delle etichette controllato dagli E2E resta lo stesso: le icone
  sono SVG e non aggiungono testo; i simboli Unicode usati oggi come icone ("▶", "▶▶", "■",
  "▦", "ƒ", …) spariscono dal testo.
- Nessuna richiesta di rete a runtime: font e icone sono nel bundle.
- Colori della spec, letterali: Platypus Dark `bg #141519`, `bg-sidebar #17181d`,
  `bg-rail #0d0e11`, `border #23252c`, `fg #c9ccd3`, `fg-strong #f2f3f5`,
  `fg-muted #6f7480`, `accent #6c63ff`; Platypus Light `bg #ffffff`,
  `bg-sidebar #f6f7f9`, `border #e6e8eb`, `accent #5b52f0`.
- Altezze: righe del navigator 24px, rientro 16px per livello, bottoni e input 28px.
- Verifica di ogni task che tocca il frontend: `npx tsc -b`, `npm run build`, poi
  `npm run tauri build -- --no-bundle` e `npm run e2e` (tutti gli scenari) da
  `apps/desktop`. Il server MySQL locale deve avere `log_bin_trust_function_creators=1`
  (vedi `docker/compose.yml`).
- Nel progetto non ci sono test unitari TypeScript: i comportamenti del frontend si provano
  negli scenari E2E (`apps/desktop/e2e/scenarios/*.mjs`), come fanno gli altri gruppi.

## Review Focus

1. **Colori personalizzati sopra i nuovi temi:** con uno sfondo personalizzato, anche
   `bg-rail`, `bg-tabbar` e `active` devono seguirlo, non restare quelli del preset
   (test nel Task 3).
2. **Chi aveva scelto "Light" o "Dark" esplicitamente** ritrova lo stesso aspetto, ora
   chiamato Classic; chi era su "System" passa a Platypus (test nel Task 3).
3. **Cache dell'aspetto della versione precedente:** al primo avvio dopo l'aggiornamento la
   cache `platypus.appearance.v1` non ha le nuove variabili; l'app non deve dipingere con
   variabili mancanti (test nel Task 3).
4. **Toolbar "solo icone":** senza parole, ogni bottone deve conservare il nome nel
   `title` e nell'`aria-label` (test nel Task 5).
5. **Font caricati dopo il primo disegno della griglia:** le colonne misurate con il font di
   ripiego vanno rimisurate e ridisegnate quando i font sono pronti (test nel Task 6).
