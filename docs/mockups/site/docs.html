Start / First connection

First connection

Open PlatypusDB and choose New connection on the start page, or press Ctrl N. Pick the database, then fill in the three sections of the form.

The three sections

Connection is where the database is: host and port, or a URL. Authentication is who you are and where the password comes from: the system keychain, a prompt every time, or a password manager. Appearance and safety sets the environment, the color and whether the connection is read only.

Paste a URL like postgresql://shop_app@db:5432/shop in the first step and the form fills itself.

Test, then save

Test connection stays at the bottom left of the window. The result appears next to it; on an error, Details shows the driver's message.
